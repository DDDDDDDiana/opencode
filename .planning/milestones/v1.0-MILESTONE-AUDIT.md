## Critical Gaps

### SESS-03: Session ownership is incomplete for message resources

- `packages/opencode/src/server/routes/session.ts` message pagination and detail handlers call `MessageV2` methods directly.
- `packages/opencode/src/session/message-v2.ts` scopes by `session_id` and `message_id`, but does not enforce `UserContext` ownership.
- Effect: if a user learns another user's `sessionID`, message read/update/delete flows can bypass the protected `Session.get()` path.

This gap forces milestone audit status `gaps_found`.
